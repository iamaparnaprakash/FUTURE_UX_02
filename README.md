# FUTURE_UX_02

## Task 2 – Mobile App UI for Appointment Booking

### Overview
This project was completed as part of my UI/UX Design Internship at Future Interns.

I redesigned a previously created website into a mobile application focused on appointment booking and user-friendly navigation.

### Features
- Product browsing
- Appointment booking
- Date & time selection
- Order confirmation
- User profile

### Tools Used
- Lunacy
- UI/UX Design Principles
- Interactive Prototyping

### Design Rationale

The app was designed with a simple and intuitive user flow to help users complete bookings with minimal effort.

Key design considerations:

* Clear visual hierarchy
* Step-by-step booking process
* Consistent color palette and branding
* Mobile-first user experience
* Easy navigation between screens
